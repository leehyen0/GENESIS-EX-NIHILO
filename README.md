# GENESIS EX NIHILO

A public interface for independent evaluation, reproducibility checks, and external collaboration around an experimental AI research project.

This repository intentionally exposes only the minimum information needed for public evaluation and collaboration. Internal theory, research lineage, private experiment traces, unpublished architecture, capability scoring, and sensitive evaluation material are not published here.

## What this repository is for

- independent black-box evaluation
- reproducibility and failure analysis
- external review and critique
- model-disjoint testing with other AI systems
- public issue-based research challenges

## What is intentionally not included

- unpublished theoretical framework
- internal research history or naming system
- private prompts, logs, or chain-of-thought
- hidden evaluation labels or answers
- private datasets, credentials, or identity material
- internal capability scores or promotion criteria

## Evaluation principle

Public evidence should be stronger than self-evaluation.

A useful evaluation should separate, as far as practical:

1. the system being tested,
2. the task or hidden target,
3. the evaluator,
4. the final scoring or verification step.

The project does not treat a new file, new label, lower cost, or self-reported improvement as evidence of a higher capability by itself.

## How to participate

Open an issue with one of the following:

- a difficult test case,
- a counterexample,
- a reproducibility attempt,
- an alternative explanation,
- an independent evaluation proposal,
- a model-disjoint test using another AI system.

Please do not post secrets, private identity documents, hidden labels, copyrighted private material, credentials, or unpublished internal research obtained from private access.

## Claims boundary

This repository is not evidence of AGI, ASI, consciousness, safety certification, or human-level superiority.

Only externally checkable results should be treated as public evidence.
