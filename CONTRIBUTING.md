# Contributing

Contributions are welcome when they improve external evaluation quality rather than expose unpublished internal research.

## Useful contributions

- difficult or adversarial test cases
- counterexamples
- independent reproductions
- model-disjoint evaluations using another AI system
- source-disjoint transfer tests
- critiques of evaluation methodology
- reports of ambiguous or unsupported claims

## Please avoid

- requesting private chain-of-thought or internal prompts
- publishing hidden answers that should remain reusable
- posting credentials or sensitive identity information
- copying unpublished material from private repositories
- treating a single result as proof of broad intelligence

## Reporting a result

Prefer an issue containing:

```text
Task
Information available to the tested system
Information hidden until commitment
Frozen output
Evaluator or model used
Rubric
Result
Negative findings / uncertainty
Reproduction details
```

Results may be positive, negative, or inconclusive. Negative evidence is useful and should not be removed merely because it conflicts with an expected result.
